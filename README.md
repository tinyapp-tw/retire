# 退休試算（PWA）

退休資產規劃的個人工具：複利試算、提領模擬、通膨換算、資產快照軌跡。**僅提供數學計算與記錄，不構成投資建議。**

## 功能

- **退休試算**：目前年齡/資產/每月投入/報酬率 → 逐月模擬到規劃歲數，即時顯示「能否撐到 X 歲」、資產耗盡點、缺口所需的每月投入（二分搜尋求解）
- **通膨換算**：所有結果以「今日幣值」呈現；退休後支出隨通膨逐年墊高
- **官方通膨資料**：內建主計總處 2001–2025 CPI 年增率，一鍵套用近 10 年（1.49%）或近 20 年（1.30%）平均
- **資產快照**：六大類資產盤點，每季記錄一次，淨資產軌跡折線圖 + 期間增減
- 資料只存裝置本機；匯出/匯入 JSON 備份；離線可用

## 模型假設（誠實版）

- 逐月複利模擬；退休前後可設不同報酬率
- 支出與年金以今日幣值輸入，隨通膨逐月墊高（複合）
- 未模擬報酬率波動（非蒙地卡羅）；報酬率是長期平均的簡化假設
- 未計入稅務；勞保/勞退請以「每月其他收入」粗估

## 數學驗證

- 零利率邊界：10 年 × 每月 1 萬 = 120 萬；等額提領恰好歸零 ✓
- 複利：6% × 12 年 = 2.0122 倍 ✓
- 實質價值：通膨 2% × 10 年 = ÷1.219 ✓
- 求解器：解出的每月投入帶回模擬不耗盡 ✓

## 本機測試

```bash
python serve.py 8131
```

## CPI 內建值更新

主計總處每年 1 月公布上一年度 CPI 年增率後，更新 `index.html` 內 `CPI` 常數並隨版本發布。資料來源：行政院主計總處（stat.gov.tw）。
